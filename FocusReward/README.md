# FocusReward

**专注学习，赚取娱乐** - 一款帮助用户建立健康生产力习惯的桌面应用程序。

## 功能特点

- **Anki 监控**: 自动读取 Anki 数据库，统计每日复习卡片数量
- **游戏进程监控**: 智能检测实际游戏进程（非仅启动器），支持多个游戏平台
- **时间兑换**: 通过复习卡片赚取游戏时间（可自定义兑换比例）
- **自动限制**: 游戏时间用尽时自动关闭游戏进程
- **历史统计**: 查看过去 30 天的学习和游戏数据图表
- **多语言支持**: 支持简体中文、繁体中文、英语、日语、韩语

## 支持的游戏平台

FocusReward 智能检测以下平台的**实际游戏进程**（不会因为仅打开启动器而计时）：

| 平台 | 检测方式 |
|------|----------|
| Steam | 注册表 + 常见安装路径 |
| Epic Games | 注册表 + 常见安装路径 |
| GOG Galaxy | 注册表 + 常见安装路径 |
| EA App / Origin | 常见安装路径 |
| Ubisoft Connect | 常见安装路径 |
| Battle.net | 常见安装路径 |
| Riot Games | 常见安装路径 |
| Xbox / Microsoft Store | 常见安装路径 |

此外，程序内置了 150+ 常见游戏进程名称的识别库。

## 系统要求

- Windows 10/11
- Python 3.8+
- Anki（用于学习追踪）
- 任意支持的游戏平台（用于游戏时间管理）

## 安装步骤

### 1. 安装 Python 依赖

```bash
cd FocusReward
pip install -r requirements.txt
```

### 2. 运行程序

```bash
python main.py
```

## 使用说明

### 首次启动

1. 启动程序后，首先会显示语言选择对话框
2. 选择您偏好的界面语言（支持 5 种语言）
3. 进入主界面

### Anki 设置

1. 点击「设置」标签页
2. 在「Anki 配置文件」下拉框中选择您的 Anki 配置文件
   - 程序会自动扫描 `%APPDATA%\Anki2` 目录下的所有配置文件
   - 如需刷新列表，点击「刷新」按钮
3. 调整兑换比例（默认: 复习 10 张卡片 = 5 分钟游戏时间）
4. 点击「保存设置」

### 日常使用

1. 程序会在后台自动监控 Anki 和游戏进程
2. 复习 Anki 卡片会自动累积游戏时间
3. 当**实际玩游戏时**（不是仅打开启动器），游戏时间会自动消耗
4. 仪表板会显示当前正在玩的游戏名称
5. 时间用尽时会收到警告通知，随后游戏进程会被自动关闭

### 紧急功能

- **紧急暂停 5 分钟**: 每日可使用一次，获得额外 5 分钟缓冲时间
- **今日解除限制**: 完全解除当日的时间限制（会被记录）

## 配置说明

所有设置保存在本地 SQLite 数据库中：

| 设置项 | 说明 | 默认值 |
|--------|------|--------|
| anki_db_path | Anki 数据库路径 | 自动检测 |
| cards_per_exchange | 每次兑换需要的卡片数 | 10 |
| minutes_per_exchange | 每次兑换获得的分钟数 | 5 |
| check_interval | 监控检查间隔（秒） | 30 |
| warning_minutes | 警告阈值（分钟） | 5 |
| language | 界面语言 | 首次启动时选择 |

## 常见问题

### Q: 程序找不到 Anki 配置文件？
A: 确保 Anki 已安装并至少运行过一次。程序会自动扫描 `%APPDATA%\Anki2` 目录。如果下拉框为空，请点击「刷新」按钮重新扫描。

### Q: 我打开了 Steam 但没有计时？
A: 这是正常的！程序只会在您**实际玩游戏时**才计时，仅打开 Steam 客户端不会消耗游戏时间。仪表板上会显示当前正在玩的游戏名称。

### Q: 如何添加不在识别列表中的游戏？
A: 目前程序会自动检测安装在游戏平台目录下的所有可执行文件。如果您的游戏安装在非标准位置，该游戏可能无法被识别。

### Q: 如何更改界面语言？
A: 在「设置」页面的底部有语言选择下拉框，选择后点击「保存设置」即可。

### Q: 如何完全退出程序？
A: 右键点击系统托盘图标，选择「退出」。
